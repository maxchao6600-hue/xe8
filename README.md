# XE8 Malaysia

Informational site for the XE8 Malaysia online gaming platform. English, Malay and Simplified Chinese live under `/en`, `/ms` and `/zh`.

```bash
npm install
npm run dev
```

Set `NEXT_PUBLIC_SITE_URL` for canonical links. Set `NEXT_PUBLIC_REGISTER_URL` and `NEXT_PUBLIC_LOGIN_URL` only when those official addresses are confirmed.

```bash
npm run lint
npm run typecheck
npm run build
```
